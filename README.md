# Telegram-бот автоматического одобрения заявок в закрытый канал

Полностью автоматический бот-привратник для приватного Telegram-канала: одобряет заявки на вступление без участия администратора и сразу пишет пользователю приветственное сообщение в ЛС.

## Как это работает

Главный сценарий — полностью автоматический, без участия админа и без обязательного /start:

1. Пользователь подаёт заявку на вступление в закрытый канал (по инвайт-ссылке с включёнными «Заявками на вступление»).
2. Бот **мгновенно одобряет заявку** — пользователь сразу добавлен в канал.
3. Бот **сразу пишет пользователю в ЛС первым**: «Заявка одобрена, ты добавлен в канал» + ссылка на канал и оферту (с фото `second.jpg`).

Telegram разрешает боту написать первым пользователю, который отправил заявку в канал, где бот — администратор, поэтому шаги 2 и 3 происходят в реальном времени в одном обработчике: сначала действие (одобрение), затем уведомление.

### Что делает /start

/start всегда отвечает — бот никогда не молчит:

- Новый пользователь → первое сообщение (`first.jpg`) с кнопкой **«Подать заявку»** (ведёт на инвайт-ссылку канала).
- Есть «застрявшая» заявка (её не удалось одобрить ранее, например у бота не было прав) → бот одобряет её и шлёт приветствие.
- Приветствие не было доставлено при одобрении (пользователь ограничил ЛС) → бот отправляет его сейчас.
- Пользователь уже в канале → бот напоминает ссылку на канал.

## Настройка

1. В Telegram создайте инвайт-ссылку канала с включённой опцией **«Заявки на вступление» (Join Requests)** и укажите её в `CHANNEL_URL`. Это обязательно: только по такой ссылке приходят заявки, которые бот одобряет.
2. Добавьте бота **администратором канала** с правом **«Приглашать пользователей»** (Invite Users via Link) — без него бот не сможет одобрять заявки.
3. Скопируйте `.env.example` в `.env` и заполните `BOT_TOKEN`, `CHANNEL_ID`, `CHANNEL_URL`.
4. Положите свои фото в `app/assets/first.jpg` и `app/assets/second.jpg` (в репозитории их нет, нужно добавить самому).
5. Запустите: `docker compose up -d --build`.

Как узнать `CHANNEL_ID`: перешлите любой пост канала боту @userinfobot либо откройте канал в Telegram Web — ID выглядит как `-100xxxxxxxxxx`.

## Надёжность

- Если одобрить заявку не удалось (нет прав), она сохраняется в SQLite и одобряется при следующем /start пользователя.
- Если ЛС не доставилось (пользователь запретил сообщения от бота), приветствие сохраняется и отправляется при /start.
- База лежит в volume `bot_data`, поэтому переживает пересборку и перезапуск контейнера.

## Диагностика

Смотрите логи: `docker compose logs -f bot`. При каждом одобрении и отправке уведомления бот пишет строку в лог.
