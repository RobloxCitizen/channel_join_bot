# Автоматическое одобрение заявок в закрытый Telegram-канал

Бот выдаёт персональную ссылку с заявкой, автоматически одобряет `chat_join_request` и отправляет пользователю подтверждение в ЛС.

## Настройка

1. Создайте бота через `@BotFather`.
2. Добавьте бота администратором закрытого канала и включите право **Приглашать пользователей**.
3. Скопируйте `.env.example` в `.env` и заполните значения.
4. Запустите: `docker compose up -d --build`.
5. Пользователь открывает бота, нажимает **Подать заявку**, затем **Перейти в канал**.

## Без Docker

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
set -a; source .env; set +a
python -m app.main
```

## Как узнать CHANNEL_ID

Перешлите сообщение из канала боту вроде `@RawDataBot` или временно выведите `chat.id` через Bot API. ID канала обычно начинается с `-100`.

## Важное ограничение Telegram

Гарантированное финальное ЛС возможно, когда пользователь сначала открыл бота через `/start`. Telegram не всегда разрешает боту первым писать пользователю, который отправил заявку только по прямой ссылке канала. Поэтому основной сценарий в проекте ведёт пользователя через кнопку внутри бота.
